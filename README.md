# point-cloud-completion
点云补全、缺失修复、机器学习点云形状补齐项目

## 项目介绍
本项目基于 **机器学习（CatBoost）+ 超参数优化（Optuna）** 实现三维点云缺失数据补全。
同时提供传统几何方法作为对比，包括：
- Numpy 随机抖动补全
- Poisson 采样补全

支持 .las 格式点云，可用于点云缺损修复、三维数据补全、形状恢复等任务。

---

## 文件说明（4 个核心算法 + 模型）
### 1. main.py
**Numpy 随机抖动点云补全算法**
- 基于随机扰动、坐标抖动生成缺失点
- 快速、轻量
- 适合小范围点云缺失修复

### 2. poisson_main.py
**Poisson 泊松采样补全算法**
- 基于泊松曲面重建原理
- 几何平滑性好
- 适合规则形状、光滑表面点云补全

### 3. train_model.py
**单核训练 CatBoost 模型（默认配置）**
- 使用 CatBoost 训练点云坐标回归模型
- 单线程训练
- 适合调试、小数据训练

### 4. train_model_cpu.py
**多核加速训练（可自定义 CPU 核心数）**
- 默认使用 **3 核 CPU 加速训练**
- 可手动修改线程数加快训练速度
- 大数据集推荐使用
- 速度比单核快 2～3 倍

## 模型说明（训练好的模型文件）
所有训练好的模型均基于 **Optuna + CatBoost** 构建：

### 模型功能
- **点云缺失坐标预测**
  输入：部分点云坐标 → 输出：缺失位置的点云坐标
- **点云密度补全**
  对稀疏、缺损区域自动生成高密度点云
- **Optuna 自动优化**
  所有模型都经过超参数搜索，精度更高

### 模型存放
- 模型文件位于 `models/` 目录
- 格式：`.cbm` 或 `.pkl`
- 可直接加载推理，无需重新训练

---

##  整体流程
- 点云预处理 → 特征构建 → Optuna 优化 → CatBoost 训练 → 缺失点预测 → 点云输出
